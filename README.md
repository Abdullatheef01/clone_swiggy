# Clone Swiggy

A simple and responsive shopping cart application developed using React.js.

## Overview

This project demonstrates how to build a basic shopping cart using React components, props, state management, and JavaScript array methods.

Users can browse products, add items to the cart, remove items, and view the total cart amount.

## Features

* Product listing
* Add to cart
* Remove from cart
* Cart item count
* Total price calculation
* Responsive design
* Reusable components
* React Router navigation

## Tech Stack

| Technology   | Usage                   |
| ------------ | ----------------------- |
| React.js     | Frontend development    |
| JavaScript   | Application logic       |
| CSS, Bootstap          | Styling                 |
| React Router | Page navigation         |
| Vite         | Development environment |

## How It Works

Products are stored as JSON data and rendered dynamically using React.

When a user selects **Add to Cart**, the selected product is added to the cart state.

When **Remove Item** is selected, the corresponding product is removed from the cart.

The total amount is calculated dynamically based on the products currently available in the cart.

## React Concepts Used

* Props
* `useState`

* Conditional rendering
* `map()`

## Getting Started

### 1. Clone the repository

```bash
git https://github.com/Abdullatheef01/clone_swiggy
```

### 2. Navigate to the project

```bash
cd clone_swiggy
```

### 3. Install dependencies

```bash
npm install
```

### 4. Run the application

```bash
npm run dev
```
